# DRUGHILL — портал семьи (Region RP)

Сайт (`public/index.html`) и сервер (`server.js`, Node.js без зависимостей) в одном сервисе Railway.
Все данные хранятся **на сервере** и общие для всех: заявки, отпуска, рапорты и премии участников сразу попадают Лидеру и Заму.

## Что делает сервер
- **Вход только через Telegram-бота.** Бот спрашивает «Это вы?», и только после кнопки «Да, это я» сайт пускает человека. Токен бота лежит на сервере, в код сайта он не попадает.
- **Роль определяется по Telegram, а не по введённому нику.** Кто есть в составе, тот получает свой ранг. Остальные — гости и могут только подать заявку в семью. `@krystalovb` всегда Лидер.
- **Права проверяются на сервере.** Заявки, рапорты, отпуска, премии подаёт участник; решения принимает Старший состав. Удалять записи и править ранги Лидера/Замов могут только Лидер и Зам. Лидера. Участники видят только свои заявки.
- **Уведомления в Telegram.** Каждая новая заявка в семью, отпуск, рапорт на повышение и премия приходит в личку Лидеру и Заму Лидера. Участнику приходит ответ о решении. Уведомления получат те, кто хотя бы раз входил на сайт через бота (так бот узнаёт их чат).
- **Уведомления лидерам.** Приходят всем, у кого на сайте ранг «Лидер» или «Зам. Лидера» (плюс `OWNER_TG`), а не только владельцу. Кроме заявок, лидеры получают сообщения о смене ранга и об исключении участника. В каждом уведомлении есть блок «Профиль на сайте» (ник, Static ID, ранг на сайте, @tg, тесты) и кнопка «Профиль на сайте», открывающая профиль в Старшем составе (`#profile/<tg>`). Кнопка работает только при https-адресе (на Railway он есть; задайте `PUBLIC_URL`, если сайт стоит на своём домене). Если лидер ни разу не входил через бота, в логе сервера будет предупреждение: бот не может написать первым.
- **«Профиль на сайте» в «Управлении составом»:** кнопка у каждого участника открывает карточку с ником, Static ID, рангом, @tg и статистикой по тестам, отпускам и откатам.
- **Ник Discord при регистрации.** При входе обязательно указывается ник в Discord (хранится в профиле, в составе и во всех заявках). Лидер и Старший состав видят его в заявках в семью, в заявках на награду, в «Профиле на сайте» и в Telegram-уведомлениях, есть кнопка «Скопировать Discord». Если игрок указал числовой ID профиля Discord, появляется кнопка «Открыть Discord»: по одному нику Discord профиль открыть нельзя. Ник можно поменять в окне «Профиль».
- **Гость видит только три действия:** «Подать заявку в семью», «Игрок семьи» и «Награда за промокод». Меню и разделы скрыты, сервер им ничего, кроме их заявок и заявок на награду, не отдаёт. После нажатия кнопка блокируется и показывает «Ожидает ответа», пока Лидер не решит.
- **Отчёты на премию и повышение:** ссылки в доказательствах показываются кнопкой «Открыть ссылку ↗», у Старшего состава есть «Принять» и «Отклонить» (участнику приходит ответ в Telegram).
- **Требования для повышения** (Старший состав → «Отчёт на повышение» → «Изменить требования»): можно менять текст, добавлять и удалять, привязывать к рангу (для всех / на 2 ранг / на 3 ранг).
- **Академия:** участник добавляет откат или видео для аттестации (ссылка + комментарий). Старший состав открывает видео кнопкой в разделе «Откаты и видео» и принимает или отклоняет. Тесты удаляются по одному кнопкой «Удалить тест».
- **Награда за промокод (промокод вводится в игре).** На сайте кода нет: игрок активирует его в игре и нажимает кнопку «Получить награду» (на экране гостя или в профиле). Старшему составу в разделе «Награды за промокод» приходит карточка с ником, Static ID, @юзом и аватаркой (есть кнопки копирования и ссылка на Telegram). Лидер выдаёт награду в игре и жмёт «Выдано» или «Отклонить», игроку приходит ответ в Telegram. Одновременно у человека может быть только одна неразобранная заявка на награду. Старые промокоды и их эндпоинты (`/api/promo/*`) удалены; поле `promoCodes` в базе осталось, чтобы старые бэкапы загружались.
- **Тесты Академии:** при создании выбирается тип: «Обычный тест» или «Тест с докой». В тесте с докой после вопросов обязательно нужно вставить ссылку на доки (видео, скрины, отчёт) и можно оставить комментарий. Сервер сам проверяет ссылку, а Старший состав видит её кнопкой «Открыть ссылку» в «Итогах тестов» и получает уведомление в Telegram.
- **Формы «Добавить» подогнаны под раздел:** Дипломатия (статус Союз/Война/Перемирие/Нейтралитет, название семьи, условия, эмблема), Автопарк (модель, ранг доступа, назначение, описание, фото), Недвижимость (название, тип, адрес, описание, фото), Новости (метка, заголовок, текст, обложка), Правила (номер пункта, название, текст). Обязательные поля проверяются, у фото есть предпросмотр.
- **Никаких системных окон браузера:** все подтверждения («Удалить тест», «Удалить запись» и т.п.) показываются красивым окном внутри сайта.
- **Сессии переживают деплой.** Токен входа подписан секретом и содержит данные пользователя, поэтому после обновления сайта человека не выкидывает, даже если файлы сессий на сервере пропали. Секрет берётся из `SESSION_SECRET` (необязательная переменная Railway), а если её нет, выводится из `BOT_TOKEN`. Поменяете токен бота или секрет, и все войдут заново. Если сервер перезапускается, сайт сам повторяет запрос и ждёт, а не сбрасывает вход.
- **Абзацы в правилах.** В тексте правила Enter даёт новую строку, пустая строка даёт новый абзац (до 1800 символов).
- «Устав» везде переименован в «Правила» (старые записи в базе подправятся при запуске).
- Заявки и отчёты на сайте обновляются у всех сами (раз в несколько секунд), перезагружать страницу не нужно.

- **Оформление сообщений бота.** Тексты прежние, меняется только начертание: заголовки жирным с подчёркиванием, подписи полей жирным, Static ID моноширинным (копируется нажатием), подсказки курсивом, прежний ранг при смене зачёркнут.
- **Фото по ссылке (новости, автопарк, недвижимость, дипломатия) работают с любого хоста.** Все внешние картинки грузятся через сервер (`/api/img`). Сервер перебирает способы: разные User-Agent и referer (обход защиты от хотлинка), варианты ссылки (Discord `cdn` ↔ `media`), внешние кэш-прокси (wsrv.nl, weserv.nl) для хостов, которые режут IP дата-центров (imgur). Ссылки-страницы (`imgur.com/a/…`, postimages, prnt.sc) разбираются автоматически. Формат определяется по содержимому файла, а не по заголовкам. **Каждое скачанное фото сохраняется в Volume (`/data/imgcache`)**: после сохранения новости/авто/объекта сервер сразу забирает фото к себе, и даже когда Discord-ссылка протухнет (они живут ограниченное время) или фото удалят с imgur, на сайте оно останется. Если и серверу не удалось, браузер пробует загрузить напрямую, потом через wsrv.nl, и только потом показывает заглушку. Лимит 10 МБ на фото, адреса во внутренней сети блокируются.

- **Фото не пропадают.** Если сервер не смог скачать фото по ссылке, но оно открылось в браузере Старшего состава (напрямую или через wsrv.nl), браузер сам отправляет его на сервер (`/api/img/save`), и оно сохраняется в Volume (`/data/imgcache`). Достаточно один раз открыть раздел с таким фото. В формах «Добавить/Изменить» появилась кнопка **«Загрузить с устройства»**: фото уменьшается до 1600 px, хранится в `/data/uploads` и не зависит от внешних ссылок (Discord и imgur их больше не сломают). Если ссылка уже мертва везде, фото нужно загрузить заново: «Изменить» → «Загрузить с устройства».

- **Порядок записей меняется перетаскиванием.** В Правилах, Автопарке, Недвижимости, Новостях и Дипломатии у Лидера и Зама у каждой карточки есть кнопка «⠿ Переместить»: зажмите её (мышью или пальцем), перетащите карточку на нужное место и отпустите. Белая полоса показывает, куда она встанет. Порядок сохраняется на сервере и виден всем. Esc отменяет перетаскивание.

- **Иконка сайта (favicon)** — призрак DRUGHILL: файлы `public/favicon-48.png`, `favicon-192.png`, `favicon.ico`, `apple-touch-icon.png`. Чтобы сменить, замените эти файлы. Браузеры кэшируют иконку надолго: после деплоя нажмите Ctrl+F5 или откройте сайт в новой вкладке.

## Деплой: GitHub → Railway
1. Загрузите **все файлы архива** в репозиторий GitHub (папки `public` и `seed` тоже).
2. Railway: **New Project → Deploy from GitHub repo**.
3. **Variables** (сервис → Variables):
   - `BOT_TOKEN` — токен бота от @BotFather. **Обязательно.** Старый токен был в коде сайта, поэтому сделайте `/revoke` у @BotFather и впишите новый.
   - `BOT_USERNAME` — имя бота без `@` (по умолчанию `drughillsite_bot`).
   - `OWNER_TG` — Telegram владельца (по умолчанию `@krystalovb`).
   - `SESSION_SECRET` — необязательно: любая длинная случайная строка для подписи входов (чтобы сессии не зависели от токена бота).
   - `NOTIFY_CHAT_IDS` — необязательно: id чатов/групп через запятую, куда дублировать уведомления.
4. **Volume (обязательно, иначе данные пропадут при каждом деплое):** сервис → **Settings → Volumes → New Volume**, Mount path `/data`. Сервер сам найдёт этот том (`RAILWAY_VOLUME_MOUNT_PATH`), больше ничего не нужно.
5. **Settings → Networking → Generate Domain** — адрес сайта.

## Первый запуск
Начальные данные берутся из `seed/db.json` (состав, пункты премий, новости и т.д.). Дальше всё живёт на сервере в Volume.
Если нужно перенести старую базу: Лидер → **База данных → Загрузить базу из файла** (`db.json`, выгруженный раньше).

## База данных (Лидер / Зам. Лидера)
- **Сохранить базу** — скачивает резервную копию `db.json` с сервера.
- **Загрузить базу из файла** — заменяет базу на сервере.
- **Сбросить базу** — возвращает начальные данные из `seed/db.json`.

## Локальный запуск
`BOT_TOKEN=... npm start`, затем http://localhost:3000 (данные в папке `data/`).

## Важно
- Вход через Telegram требует игровой ник и Static ID. Дальше внутри сайта человек выбирает «Игрок семьи», «Подать заявку в семью» или «Награда за промокод». Во всех случаях Лидер и Зам получают уведомление; доступ к порталу открывается только после одобрения («Принять» в разделе «Управление составом»).
- Принятие в семью: гость подаёт заявку, Старший состав нажимает «Принять», и человек становится участником (1. Контракт) сразу, без перезахода.
- Результат теста считает браузер участника, сервер ему доверяет. Для кадрового решения это нормально, для призов лучше перепроверять.
- Файл `/db.json` больше не открыт всем: данные отдаются только после входа.
