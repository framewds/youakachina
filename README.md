# DRUGHILL — портал семьи (Region RP)

Сайт (`public/index.html`) и сервер (`server.js`, Node.js без зависимостей) в одном сервисе Railway.
Все данные хранятся **на сервере** и общие для всех: заявки, отпуска, рапорты и премии участников сразу попадают Лидеру и Заму.

## Что делает сервер
- **Вход только через Telegram-бота.** Бот спрашивает «Это вы?», и только после кнопки «Да, это я» сайт пускает человека. Токен бота лежит на сервере, в код сайта он не попадает.
- **Роль определяется по Telegram, а не по введённому нику.** Кто есть в составе, тот получает свой ранг. Остальные — гости и могут только подать заявку в семью. `@krystalovb` всегда Лидер.
- **Права проверяются на сервере.** Заявки, рапорты, отпуска, премии подаёт участник; решения принимает Старший состав. Удалять записи и править ранги Лидера/Замов могут только Лидер и Зам. Лидера. Участники видят только свои заявки.
- **Уведомления в Telegram.** Каждая новая заявка в семью, отпуск, рапорт на повышение и премия приходит в личку Лидеру и Заму Лидера. Участнику приходит ответ о решении. Уведомления получат те, кто хотя бы раз входил на сайт через бота (так бот узнаёт их чат).
- Заявки и отчёты на сайте обновляются у всех сами (раз в несколько секунд), перезагружать страницу не нужно.

## Деплой: GitHub → Railway
1. Загрузите **все файлы архива** в репозиторий GitHub (папки `public` и `seed` тоже).
2. Railway: **New Project → Deploy from GitHub repo**.
3. **Variables** (сервис → Variables):
   - `BOT_TOKEN` — токен бота от @BotFather. **Обязательно.** Старый токен был в коде сайта, поэтому сделайте `/revoke` у @BotFather и впишите новый.
   - `BOT_USERNAME` — имя бота без `@` (по умолчанию `drughillsite_bot`).
   - `OWNER_TG` — Telegram владельца (по умолчанию `@krystalovb`).
   - `NOTIFY_CHAT_IDS` — необязательно: id чатов/групп через запятую, куда дублировать уведомления.
4. **Volume (обязательно, иначе данные пропадут при каждом деплое):** сервис → **Settings → Volumes → New Volume**, Mount path `/data`. Сервер сам найдёт этот том (`RAILWAY_VOLUME_MOUNT_PATH`), больше ничего не нужно.
5. **Settings → Networking → Generate Domain** — адрес сайта.

## Первый запуск
Начальные данные берутся из `seed/db.json` (состав, пункты премий, новости и т.д.). Дальше всё живёт на сервере в Volume.
Если нужно перенести старую базу: Лидер → **База данных → Загрузить базу из файла** (`db.json`, выгруженный раньше).

## База данных (Лидер / Зам. Лидера)
- **Сохранить базу** — скачивает резервную копию `db.json` с сервера.
- **Загрузить базу из файла** — заменяет базу на сервере.
- **Сбросить базу** — возвращает начальные данные из `seed/db.json`.

## Локальный запуск
`BOT_TOKEN=... npm start`, затем http://localhost:3000 (данные в папке `data/`).

## Важно
- Принятие в семью: гость подаёт заявку, Старший состав нажимает «Принять», и человек становится участником (1. Контракт) сразу, без перезахода.
- Результат теста считает браузер участника, сервер ему доверяет. Для кадрового решения это нормально, для призов лучше перепроверять.
- Файл `/db.json` больше не открыт всем: данные отдаются только после входа.
